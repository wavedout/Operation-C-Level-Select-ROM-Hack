# Changelog

## 1.0 — 2026-09-25

- Initial public release.
- Expanded the hidden stage selector with Area, Weapon, and Lives settings.
- Retained the original slide-in animation and polished the panel layout.
- Added all five native weapon presets and 3, 5, 10, 20, or Infinite lives.
- Preserved weapon pickups, checkpoints, deaths, continues, stage transitions,
  credits, and the stock post-credits loop.
- Verified every menu option, all five stages, the Area 4 boss transition, the
  complete ending sequence, and a full playthrough on Super Game Boy.

## Pre-release development — 2026-09-25

- Internal iterations refined the menu layout and weapon initialization, moved
  injected code away from stage data, fixed the Area 4 boss transition, and
  corrected bank-safe Up/Down navigation before the public 1.0 release.
